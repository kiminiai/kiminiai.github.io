# 리눅스 기초 1편: Shell, 디렉토리 구조, 파일 명령어 정리

> 이 글은 이어드림스쿨 리눅스 수업 내용을 바탕으로 정리한 글이다.  
> 단순히 명령어를 외우는 것보다, 리눅스에서 명령어가 어떤 구조로 동작하는지 이해하는 것을 목표로 했다.

리눅스를 처음 배우면 `ls`, `cd`, `pwd`, `mkdir` 같은 명령어가 많이 나온다.  
처음에는 명령어를 하나씩 외우려고 하게 되지만, 그렇게 공부하면 금방 헷갈린다.

그래서 이번 글에서는 리눅스 명령어를 다음 흐름으로 정리한다.

1. 리눅스와 Shell의 관계
2. CLI와 GUI의 차이
3. 디렉토리 이동과 조회 명령어
4. 파일과 디렉토리 생성, 복사, 이동, 삭제
5. 권한과 관리자 명령어
6. 패키지 관리 명령어 `apt`

---

## 1. 리눅스란 무엇인가?

리눅스는 유닉스 기반의 운영체제이다.  
운영체제는 하드웨어와 응용 프로그램 사이에서 시스템 자원을 관리하고, 사용자가 프로그램을 실행할 수 있도록 도와주는 소프트웨어이다.

리눅스의 대표적인 특징은 다음과 같다.

| 특징 | 설명 |
|---|---|
| 유닉스 기반 | 서버와 개발 환경에서 많이 사용되는 운영체제 계열 |
| 멀티 유저 지원 | 여러 사용자가 하나의 시스템을 사용할 수 있음 |
| 멀티 태스킹 지원 | 여러 작업을 동시에 실행할 수 있음 |
| CLI / GUI 모두 지원 | 명령어 기반 환경과 그래픽 환경 모두 사용 가능 |
| 강력한 네트워킹 기능 | 서버, 원격 접속, 네트워크 관리에 적합 |

리눅스는 서버 환경에서 특히 많이 사용된다.  
데이터 분석이나 머신러닝을 공부할 때도 서버, 클라우드, 도커, 배포 환경을 다루게 되면 리눅스를 자주 만나게 된다.

---

## 2. Shell은 사용자의 명령을 Kernel에 전달한다

리눅스 구조를 이해할 때 가장 먼저 알아야 할 개념은 `Shell`과 `Kernel`이다.

![리눅스 구조](/img/linux-basics/linux-structure.svg)

`Kernel`은 운영체제의 핵심 부분이다.  
하드웨어, 메모리, 프로세스, 파일 시스템 같은 시스템 자원을 직접 관리한다.

하지만 사용자가 커널에 직접 명령을 내리지는 않는다.  
사용자는 Shell에 명령어를 입력하고, Shell은 그 명령을 해석해서 커널에 요청한다.

정리하면 다음과 같다.

| 구성 요소 | 역할 |
|---|---|
| 사용자 | 명령어 입력 |
| Shell | 명령어 해석 후 Kernel에 요청 |
| Kernel | 실제 시스템 자원 제어 |
| Hardware | CPU, 메모리, 디스크 등 물리 장치 |

Shell의 종류에는 `bash`, `sh`, `csh`, `ksh` 등이 있다.  
그중 `bash`는 리눅스에서 가장 흔하게 사용되는 기본 Shell이다.

---

## 3. CLI와 GUI의 차이

컴퓨터를 사용하는 방식은 크게 `GUI`와 `CLI`로 나눌 수 있다.

| 구분 | 의미 | 예시 |
|---|---|---|
| GUI | 아이콘, 버튼, 창 등 그래픽 요소로 조작하는 방식 | Windows, macOS Finder |
| CLI | 명령어를 입력해서 컴퓨터와 상호작용하는 방식 | Linux Terminal, Windows CMD |

GUI는 눈으로 보고 클릭할 수 있어 직관적이다.  
반면 CLI는 처음에는 어렵지만, 반복 작업과 서버 관리에 강하다.

예를 들어 수백 개의 파일 이름을 한 번에 바꾸거나, 서버에서 로그를 검색하거나, 원격 컴퓨터에 접속해서 작업할 때는 CLI가 훨씬 효율적이다.

## 4. 기본 명령어: 내가 누구이고 어디에 있는지 확인하기

리눅스를 처음 사용할 때는 현재 사용자와 현재 위치를 확인하는 명령어부터 익히는 것이 좋다.

| 명령어 | 의미 |
|---|---|
| `whoami` | 현재 로그인한 사용자 ID 확인 |
| `passwd` | 현재 사용자의 비밀번호 변경 |
| `pwd` | 현재 디렉토리 위치 출력 |
| `ls` | 현재 디렉토리의 파일/디렉토리 목록 출력 |
| `cd` | 디렉토리 이동 |
| `--help` | 명령어 사용법 확인 |

예를 들어 현재 위치를 확인하려면 다음 명령어를 사용한다.

```bash
pwd
```

현재 디렉토리의 목록을 보려면 다음 명령어를 사용한다.

```bash
ls
```

명령어 사용법이 헷갈릴 때는 `--help`를 붙이면 된다.

```bash
ls --help
```

처음부터 모든 옵션을 외울 필요는 없다.  
중요한 것은 명령어의 기본 역할을 먼저 이해하고, 필요한 옵션은 그때그때 찾아보는 것이다.

---

## 5. `ls` 옵션 이해하기

`ls`는 현재 디렉토리에 있는 파일과 디렉토리 목록을 출력하는 명령어이다.  
가장 자주 사용하는 옵션은 다음과 같다.

| 명령어 | 의미 |
|---|---|
| `ls` | 현재 디렉토리 목록 출력 |
| `ls -l` | 상세 정보까지 출력 |
| `ls -a` | 숨김 파일 포함 출력 |
| `ls -al` | 숨김 파일 포함 + 상세 정보 출력 |

예를 들어 숨김 파일까지 자세히 보고 싶다면 다음과 같이 입력한다.

```bash
ls -al
```

리눅스에서 `.`으로 시작하는 파일은 숨김 파일로 취급된다.  
예를 들어 `.bashrc`, `.gitignore` 같은 파일이 이에 해당한다.

## 6. 리눅스 파일 시스템은 트리 구조다

리눅스의 파일 시스템은 디렉토리와 파일로 구성되어 있다.  
그리고 전체 구조는 하나의 루트 디렉토리(`/`)에서 시작하는 트리 구조이다.

![리눅스 파일 시스템 트리 구조](/img/linux-basics/filesystem-tree.svg)

윈도우에서는 `C:\`, `D:\`처럼 드라이브 단위가 익숙하다.  
하지만 리눅스에서는 모든 파일과 디렉토리가 루트 디렉토리(`/`) 아래에 연결된다.

예를 들어 사용자의 홈 디렉토리는 보통 다음과 같은 경로를 가진다.

```bash
/home/user01
```

현재 위치를 확인할 때는 `pwd`, 다른 위치로 이동할 때는 `cd`를 사용한다.

```bash
pwd
cd /home/user01
```

상위 디렉토리로 이동할 때는 `..`을 사용한다.

```bash
cd ..
```

홈 디렉토리로 이동할 때는 다음과 같이 입력할 수 있다.

```bash
cd ~
```

## 7. 파일과 디렉토리 명령어를 역할별로 정리하기

파일과 디렉토리 명령어는 하나씩 외우기보다 역할별로 묶어서 이해하는 것이 좋다.

![파일과 디렉토리 명령어](/img/linux-basics/file-commands.svg)

대표적인 명령어는 다음과 같다.

| 명령어 | 역할 | 예시 |
|---|---|---|
| `mkdir` | 디렉토리 생성 | `mkdir logs` |
| `touch` | 빈 파일 생성 | `touch memo.txt` |
| `cat` | 파일 내용 출력 | `cat memo.txt` |
| `cp` | 파일/디렉토리 복사 | `cp a.txt b.txt` |
| `mv` | 파일/디렉토리 이동 또는 이름 변경 | `mv old.txt new.txt` |
| `rm` | 파일/디렉토리 삭제 | `rm a.txt` |
| `rmdir` | 빈 디렉토리 삭제 | `rmdir empty_dir` |

---

## 8. 디렉토리 생성: `mkdir`

`mkdir`은 디렉토리를 생성하는 명령어이다.

```bash
mkdir logs
```

위 명령어를 실행하면 현재 위치에 `logs`라는 디렉토리가 생성된다.

여러 단계의 디렉토리를 한 번에 만들고 싶다면 `-p` 옵션을 사용할 수 있다.

```bash
mkdir -p project/data/raw
```

`-p` 옵션은 중간 디렉토리가 없으면 함께 생성해준다.

---

## 9. 빈 파일 생성: `touch`

`touch`는 빈 파일을 생성할 때 자주 사용한다.

```bash
touch memo.txt
```

위 명령어를 실행하면 `memo.txt`라는 빈 파일이 생성된다.

이미 존재하는 파일에 `touch`를 사용하면 파일의 수정 시간이 갱신된다.

---

## 10. 파일 내용 출력: `cat`

`cat`은 파일 내용을 화면에 출력하는 명령어이다.

```bash
cat memo.txt
```

짧은 파일을 확인할 때는 `cat`이 편하다.  
하지만 로그 파일처럼 내용이 너무 긴 파일을 볼 때는 `cat`만으로는 불편할 수 있다.

이럴 때는 다음 명령어를 함께 알아두면 좋다.

| 명령어 | 의미 |
|---|---|
| `head` | 파일의 앞부분 출력 |
| `tail` | 파일의 뒷부분 출력 |
| `more` | 화면 단위로 출력 |
| `wc` | 줄 수, 단어 수, 문자 수 출력 |
| `diff` | 파일 비교 |
| `which` | 명령어의 절대 경로 확인 |
| `alias` | 명령어 별칭 지정 |

예를 들어 파일의 처음 10줄만 보고 싶다면 다음과 같이 입력한다.

```bash
head memo.txt
```

마지막 10줄을 보고 싶다면 다음과 같이 입력한다.

```bash
tail memo.txt
```

---

## 11. 복사: `cp`

`cp`는 파일이나 디렉토리를 복사하는 명령어이다.

```bash
cp a.txt b.txt
```

위 명령어는 `a.txt` 파일을 복사해서 `b.txt`를 만든다.

디렉토리를 복사하려면 `-r` 옵션이 필요하다.

```bash
cp -r old_dir new_dir
```

주요 옵션은 다음과 같다.

| 옵션 | 의미 |
|---|---|
| `-r` | 하위 디렉토리와 파일까지 재귀적으로 복사 |
| `-p` | 소유자, 그룹, 권한, 시간 정보를 유지해서 복사 |

---

## 12. 이동과 이름 변경: `mv`

`mv`는 파일이나 디렉토리를 이동할 때 사용한다.  
또한 이름을 변경할 때도 사용한다.

파일 이름을 바꾸는 예시는 다음과 같다.

```bash
mv old.txt new.txt
```

파일을 다른 디렉토리로 이동하는 예시는 다음과 같다.

```bash
mv memo.txt ./backup/
```

즉, `mv`는 “이동”과 “이름 변경” 두 가지 역할을 모두 한다.

---

## 13. 삭제: `rm`, `rmdir`

파일 삭제는 `rm`을 사용한다.

```bash
rm memo.txt
```

디렉토리와 그 안의 파일까지 삭제하려면 `-r` 옵션을 사용한다.

```bash
rm -r old_dir
```

강제로 삭제하려면 `-f` 옵션을 사용할 수 있다.

```bash
rm -f memo.txt
```

디렉토리와 하위 파일까지 묻지 않고 삭제하려면 다음과 같이 입력한다.

```bash
rm -rf old_dir
```

하지만 `rm -rf`는 매우 조심해야 한다.  
삭제 후 되돌리기 어렵기 때문이다.

반면 `rmdir`은 빈 디렉토리만 삭제할 수 있다.

```bash
rmdir empty_dir
```

정리하면 다음과 같다.

| 명령어 | 의미 |
|---|---|
| `rm` | 파일 삭제 |
| `rm -r` | 디렉토리와 하위 파일까지 삭제 |
| `rm -f` | 확인 없이 강제 삭제 |
| `rm -rf` | 하위 파일 포함 강제 삭제 |
| `rmdir` | 빈 디렉토리 삭제 |

## 14. 관리자 권한: root와 sudo

리눅스에서 `root`는 모든 권한을 가진 최고 관리자 계정이다.  
운영체제의 거의 모든 것을 제어할 수 있다.

일반 사용자는 시스템에 중요한 변경을 직접 수행할 수 없기 때문에 관리자 권한이 필요할 때 `sudo`를 사용한다.

```bash
sudo apt update
```

`sudo`는 “관리자 권한으로 이 명령어를 실행하겠다”는 의미이다.

하지만 `sudo`를 남용하면 위험하다.  
특히 삭제 명령어와 함께 사용할 때는 신중해야 한다.

```bash
sudo rm -rf some_directory
```

이런 명령어는 실수하면 시스템 파일이나 중요한 데이터를 삭제할 수 있다.

## 15. 파일 권한과 소유권: `chmod`, `chown`

리눅스는 파일마다 소유자와 권한을 가진다.  
누가 읽을 수 있는지, 쓸 수 있는지, 실행할 수 있는지를 권한으로 관리한다.

| 명령어 | 의미 |
|---|---|
| `chmod` | 파일 권한 변경 |
| `chown` | 파일 소유자 변경 |

예를 들어 스크립트 파일에 실행 권한을 추가하려면 다음과 같이 입력한다.

```bash
chmod +x run.sh
```

파일 소유자를 변경하려면 다음과 같이 입력한다.

```bash
sudo chown user01 file.txt
```

권한은 리눅스를 사용할 때 자주 마주치는 개념이다.  
처음에는 `Permission denied` 오류가 나오면 권한 문제일 가능성을 떠올리면 된다.

---

## 16. 패키지 관리: `apt`

`apt`는 우분투와 같은 데비안 계열 리눅스에서 소프트웨어를 설치, 제거, 업데이트할 때 사용하는 패키지 관리 도구이다.

| apt 명령어 | 기존 명령어 | 의미 |
|---|---|---|
| `apt install` | `apt-get install` | 패키지 설치 |
| `apt remove` | `apt-get remove` | 패키지 제거 |
| `apt update` | `apt-get update` | 패키지 목록 업데이트 |
| `apt search` | `apt-cache search` | 패키지 검색 |
| `apt show` | `apt-cache show` | 패키지 정보 확인 |

예를 들어 `tree` 패키지를 설치하려면 다음과 같이 입력한다.

```bash
sudo apt update
sudo apt install tree
```

여기서 `apt update`는 프로그램을 업데이트하는 명령이 아니다.  
설치 가능한 패키지 목록을 최신 상태로 가져오는 명령이다.

실제 패키지 설치는 `apt install`로 수행한다.

| 복사 | `cp`, `cp -r`, `cp -p` |
| 이동/이름 변경 | `mv` |
| 삭제 | `rm`, `rm -r`, `rm -f`, `rm -rf`, `rmdir` |
| 권한/소유권 | `chmod`, `chown` |
| 관리자 권한 | `sudo` |
| 패키지 관리 | `apt install`, `apt remove`, `apt update`, `apt search`, `apt show` |

## 18. 정리하며 배운 점

리눅스 명령어는 처음 보면 외울 것이 많아 보인다.  
하지만 역할별로 묶어서 보면 구조가 보인다.

- 현재 위치 확인: `pwd`
- 목록 확인: `ls`
- 이동: `cd`
- 생성: `mkdir`, `touch`
- 확인: `cat`, `head`, `tail`
- 복사/이동: `cp`, `mv`
- 삭제: `rm`, `rmdir`
- 권한 관리: `chmod`, `chown`, `sudo`
- 패키지 관리: `apt`

결국 리눅스 기초 명령어는 “파일과 디렉토리를 다루는 방법”에서 시작한다.  
서버, 도커, 클라우드, 데이터 분석 환경을 다루기 위해서는 이 기본 명령어들이 기반이 된다.

다음 글에서는 정규 표현식, `grep`, 리다이렉션, 파이프, 마운트, 프로세스, SSH를 정리한다.
